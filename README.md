# Frontend Zone

Playground de componentes e padrões de UI em React — laboratório frontend.

## Stack

- Vite
- React 18
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix), React Router, TanStack Query

## Correr localmente

```bash
npm install && npm run dev
```
